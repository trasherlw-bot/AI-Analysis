Takes an Excel list of HelpDeskEddy ticket numbers, downloads the tickets, masks personal data, and splits client requests from AI replies.

HDE_EMAIL / HDE_API_KEY are not set on the server. Edit .env and restart the container.
Personal names are not masked (the name-recognition module is not installed). Emails, phones, links and long numbers are masked, but check the result by eye before sharing it.

1. Add a file

Upload an .xlsx here, or copy it into /opt/hde-analysis/data/inbox/ with WinSCP. The ticket numbers must be in a column named Заявка.
